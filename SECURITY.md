# Security Policy

## Supported versions

The project currently supports security fixes for:

| Version | Supported |
| --- | --- |
| Latest `0.x` release | Yes |
| `main` branch | Best effort |
| Older releases | No |

## Reporting a vulnerability

Do not open public issues for security problems.

Use GitHub private vulnerability reporting for this repository:

- <https://github.com/Juhwa-Lee1023/prepared-text-ios/security/advisories/new>

If that path is unavailable, contact the maintainers privately before sharing details publicly.

Please include:

- affected version or commit
- impact summary
- reproduction steps or proof of concept
- any suggested mitigation, if you have one

## Disclosure expectations

- Give maintainers a reasonable amount of time to investigate and patch the issue.
- Avoid publishing exploit details before a fix or mitigation is available.
- Keep all pre-disclosure discussion private.

## What not to report publicly

- unpatched vulnerabilities
- private proof-of-concept exploits
- secrets, tokens, credentials, or private infrastructure details
