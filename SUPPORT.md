# Support

## Usage questions

For usage questions and integration guidance, prefer GitHub Discussions:

- <https://github.com/Juhwa-Lee1023/prepared-text-ios/discussions>

If Discussions is not enabled yet, open a docs or maintenance issue only when you can point to a concrete gap in the repository documentation.

## Bug reports

Use the bug report issue form:

- <https://github.com/Juhwa-Lee1023/prepared-text-ios/issues/new/choose>

Please include a minimal reproduction and the exact commands or runtime context that shows the problem.

## Security issues

Do not file public security issues.

Follow [SECURITY.md](SECURITY.md) and use:

- <https://github.com/Juhwa-Lee1023/prepared-text-ios/security/advisories/new>
